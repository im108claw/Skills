# Agent Skills Library (im108claw/Skills)

Notion **DB_Skills** (https://app.notion.com/p/45387f60b7414141b6e7ace36caf062e) と100%同期する AI スキルライブラリです。

## 特徴
- **Notion DB_Skills (SSOT)**: Notion上のスキルデータベースを正本として同期管理。
- **Agent-neutral**: ChatGPT, Claude Code, Grok, Cursor, Hermes Agent等で共有可能。
- **Notion Agent Skills Standard**: 公式 Agent Skills 規格に準拠。

## 利用方法
```bash
npx skills add https://github.com/im108claw/Skills
```
